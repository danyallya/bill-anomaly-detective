# Offline behavior

The PWA stores the public entry page, offline notice, icon and versioned static assets after the first visit. It never caches API responses. A synthetic-only comparison is written to IndexedDB in the current browser profile and remains available across reloads; there is no account, application-level encryption, sync, backup or conflict handling. Do not enter actual utility usage values.

The comparison stores two month labels and kWh totals, but no provider, tariff, meter or account identifier, address, cost, bill image or user-entered cause. Delete it in the app or clear the browser profile; browser backups and secure erasure are not covered. The comparison uses totals as entered and does not normalize different bill durations.
